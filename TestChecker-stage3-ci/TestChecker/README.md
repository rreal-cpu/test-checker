# Test Checker (stage 3)

Open in Android Studio (Koala or newer), sync Gradle (8.7+), run on Android 9+.

Stage 1: exam + key, printable bubble sheet (PDF), offline bubble scanning.
Stage 2: item types with points/rubrics; AI checking of the student's actual paper (Anthropic API key in Settings).
Stage 3: every checked paper is saved with per-item detail; Papers screen with class stats, item analysis
(hardest items first), rename/delete, and a per-item CSV export; "Import key from photo (AI)" builds items from a
photo of your answer key.

Print the bubble sheet at 100% (not "fit to page"). AI output is a draft: check highlighted items and any key
imported by AI before using it.
